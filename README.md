# Portfolio Website - Web Technologies & Software Engineering

A modern, responsive portfolio website showcasing academic work and projects in Web Technologies and Software Engineering courses.

## Features

### ✨ Design Highlights
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Fully Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- **CSS Grid & Flexbox**: Modern layout techniques for optimal structure
- **Smooth Animations**: CSS transitions and hover effects throughout
- **Interactive Elements**: Dynamic navigation, skill bars, and scroll effects

### 📋 Sections Included

1. **Header (Navigation)**
   - Logo/Student Name with Profile Picture

   - Smooth scroll navigation

2. **Home Section**
   - Eye-catching hero section with profile image
   - Introduction tagline
   - Call-to-Action buttons (View Projects, Contact Me)

3. **About Me**
   - Academic background

4. **Learning**

7. **Projects**

8. **Contact**

   - Social media links
   - Contact form

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A text editor (VS Code, Sublime Text, etc.)

### Installation

1. **Clone or download** this repository
2. **Open** `index.html` in your web browser
3. **Customize** the content with your own information

### Customization Guide

#### Replace Placeholder Images
- Replace `https://via.placeholder.com/50` in the header with your profile picture
- Replace `https://via.placeholder.com/300` in the home section with your main profile image

#### Update Personal Information
1. **Student Name**: Edit `.student-name` in the header
2. **Semester & Department**: Update `.semester-dept` text
3. **About Me**: Modify the content in the `#about` section
4. **Skills**: Adjust skill percentages in the `#skills` section
5. **Contact**: Update contact information in the `#contact` section

#### Modify Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --accent-color: #ec4899;
    /* ... more variables */
}
```
